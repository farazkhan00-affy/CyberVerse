# 🛡️ CyberVerse

CyberVerse is a modern cybersecurity platform built to provide security analysis, web utilities, AI-powered assistance, and authentication in one place.

## 🚀 Features

- 🔐 Secure User Authentication (JWT)
- 🔄 Refresh Token Authentication
- 🔑 Forgot & Reset Password
- 🌐 Google OAuth Login
- 🐙 GitHub OAuth Login
- 🤖 AI Assistant
- 📩 Contact Form
- 🛡️ Cybersecurity Web Tools
- 📱 Fully Responsive Design
- ⚡ Modern UI/UX
- 🌙 Dark Theme

## 🛠️ Tech Stack

### Frontend
- React
- Vite
- TypeScript
- Tailwind CSS
- Framer Motion
- React Router

### Backend
- FastAPI
- SQLAlchemy
- PostgreSQL
- JWT Authentication
- OAuth (Google & GitHub)
- Uvicorn

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/CyberVerse.git
```

Frontend

```bash
cd frontend
npm install
npm run dev
```

Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
```
